# XP Pen tablet config for MS Whiteboard

## Pen settings

Key              |  Shortcut  | MS Whiteboard tool
-----------------|------------|--------------------
Bottom button    | Alt+X      | *Ereaser*  
Top button       | Alt+W      | *Switch to pen*

## Roller settings

Undo/Redo - (Ctrl-Z, Ctrl-Y)

## Shortcut keys

Key |  Shortcut  | MS Whiteboard tool
----|------------|--------------------
K1  |  Alt+I     | *Highliter*
K2  |  Alt+A     | *Arrow*
K3  |  Alt+Q     | *Lasso*
K4  |  Alt+H     | *Hand*
K5  |  Ctrl+Z    | *Undo*
K6  |  Ctrl+Y    | *Redo*
