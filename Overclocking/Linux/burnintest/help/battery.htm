Battery

This test checks the battery's level (mWh) and compares this to a threshold value. The threshold value can be specified in absolute, or percentage terms relative the the batteries designed capacity. Threshold exceeded errors will be raised if the battery level drops below the threshold specified.

 

These checks can be carried out before the main tests as a pre-test (checks once), and/or during the main tests (checks once per minute).

The Battery information will be logged in an interim result summary (once per minute) and in the final result summary.

 

See the Battery Preferences window for test settings.
