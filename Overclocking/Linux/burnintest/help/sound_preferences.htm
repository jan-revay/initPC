Device Name

Sound device name used for testing. Default is "plughw" but can also be set to "default" (or other sound alias for system, should be left as plughw in most cases).

 

Max Distortion

Select the maximum distortion allowable for the loopback test. The values available are between 1 and 20 percent. 1% represents a low level of distortion.
