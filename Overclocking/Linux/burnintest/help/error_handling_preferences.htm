Action on Error

When BurnInTest detects an error, three options are available:

 

Continue

The error counter is incremented and testing continues.

 

Beep and Continue

The error counter is incremented, the computer beeps and testing continues.

 

Auto Stop Tests

All windows (except the main window) are closed and all the tests are stopped. The failed window is then displayed.
